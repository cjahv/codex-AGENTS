# 导航与图标系统参考

## 使用方式

- 在任务涉及侧边导航、左轨工作台、导航收起态、图标统一性、图标选中态时读取本文件。
- 优先把这些系统当作“成熟约束样本”，用来校准结构、密度和状态表达，不要机械复刻品牌表皮。
- 需要最新官方细节时，再访问文末官方链接核对。

## 快速判断

- SAP Fiori 适合校准企业级工作台的稳定分层、可折叠左轨和系统级纪律。
- Atlassian 适合校准高频切换、多产品/多项目环境下的轻量左轨和空间利用。
- Fluent 2 适合校准图标命名、选中态、尺寸和主题切换下的可读性。

## SAP Fiori Side Navigation

### 该学什么

- 侧边导航是应用级垂直菜单，重点是让用户在不同页面/功能段之间稳定切换。
- Web 侧边导航支持嵌套层级，但应保持克制；官方说明支持最多 3 级嵌套。
- 桌面上优先使用嵌入式展开/收起；触控设备更偏向覆盖式，手机上直接全屏承载。
- 固定 footer 区域和主导航区分离，低频但系统级入口放到底部，不跟随主列表滚动。
- 第一项命名为 `Home` 是一个很强的“回到入口页”信号，适合企业后台做稳定锚点。

### 审查翻译

- 如果左轨同时承载主导航、帮助、筛选、营销和临时工具，判定为骨架失焦。
- 如果超过 3 级还在继续嵌套，通常不是导航设计成功，而是 IA 失控。
- 如果收起后子项只能靠猜图标理解，说明不具备收起资格；应保留文字、改信息架构，或改成覆盖式。
- 如果底部系统入口过多，或滚动后消失，说明“全局入口”和“内容入口”没有分层。

### 适用气质

- ERP、审批、运营、制造、医疗等高频业务工作台。
- 需要稳定入口、明确归属感、强规则感的后台系统。

## Atlassian Side Navigation

### 该学什么

- Atlassian 旧 `Side navigation` 已标记计划弃用，官方建议转向 `Navigation system`；更新知识时要把它当“迁移中的模式”，不要当静态金标准。
- 新体系把布局、侧边导航和侧边条目拆开，强调导航区域是页面结构的一部分，而不是孤立组件。
- Atlassian 的布局文档给出很实用的宽度基线：`collapsed 56px`，`default 320px`，适合桌面端左轨起点估算。
- 左轨与主内容区是联动关系，左轨出现时主内容栅格要跟着收缩，而不是简单把导航压在内容上面。
- 侧边导航更适合承载导航元素本身；支持性内容应进入 aside，而不是混在导航树里。

### 审查翻译

- 如果你的左轨把“导航”和“辅助面板”做成一锅粥，优先拆成 navigation 与 aside 两个职责。
- 如果收起宽度远大于图标识别需要，说明浪费横向空间；如果远小于 56px 级别，通常会伤害命中率和辨识。
- 如果页面布局没有因为左轨而重算内容宽度，容易造成表格、表单、看板的阅读节奏断裂。
- 如果项目/空间切换频繁，却没有稳定的左轨定位感，用户会更依赖搜索和记忆，导航价值会被削空。

### 适用气质

- 多项目协作、知识管理、任务流转、开发平台、内部工具门户。
- 需要在高密度内容和高频切换之间找平衡的产品。

## Fluent 2 Iconography

### 该学什么

- Fluent 把图标分成 system、product launch、file 三类；后台与应用导航主要看 system icons。
- System icons 有 `Regular` 和 `Filled` 两个主题。Regular 更适合 wayfinding 和默认态，Filled 更适合选中态或需要更重可读性的时刻。
- 12px 图标更适合信息提示，不适合作为交互目标本体；交互图标尺寸应随设备和命中需求放大。
- 图标命名遵循“按形状/物体命名，不按功能命名”，例如 `Shield`，不是 `Security`。
- 修饰符要克制，且放在右下角；一旦修饰导致语义复杂或图形拥挤，就不应继续叠加。
- System icon 着色要克制，通常只用单色；产品图标不要随意改色，也不要拿来代替品牌 Logo。

### 审查翻译

- 默认态图标如果已经很重，选中态就缺少拉开空间；这种情况下优先回退默认态权重，而不是继续堆颜色。
- 如果把 12px 级图标当可点击主入口，是可用性问题，不只是视觉问题。
- 如果命名靠业务语义硬套，最终通常会选出隐喻失真的图标；先找形状隐喻，再让文案补足业务语义。
- 如果一个导航混用 outline、filled、多色品牌图标和文件图标，说明图标层级和语义完全失控。

### 适用气质

- 微软生态、B2B 桌面工具、生产力软件。
- 需要在亮暗主题都维持稳定可读性的图标系统。

## 组合使用建议

- 做企业级左轨：用 SAP Fiori 校准层级和固定系统入口，用 Atlassian 校准桌面宽度与内容联动。
- 做图标审查：用 Fluent 2 校准默认态/选中态、尺寸和命名；不要只盯“好不好看”。
- 做收起态：先确认收起后仍有定位感，再确认图标是否足以独立承担识别；否则宁可保留文字或只在大屏允许收起。
