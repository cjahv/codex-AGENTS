# 视觉认知约束

## 使用方式

- 在审查信息密度、视觉锚点、图表替代、动效和状态提示时读取本文件。
- 把这些原则当作设计启发式，不要把它们当作必须逐条命中的考试题。
- 如果用户明确要求“最新研究”“请核实”，再联网查最新资料并补上来源。

## 核心原则

### 1. 中央视觉区承担关键判断

- 人眼中心区域更适合识别细节、阅读小字、做精确判断。
- 关键 KPI、主操作、告警、结果反馈要靠近用户的主视觉锚点。
- 外围区域适合放背景、次级导航、辅助说明、低频工具，不适合塞满高风险细节。

### 2. 扫视是有成本的

- 用户不是一次把整页读完，而是在若干个停留点之间跳转扫描。
- 每多一个“看起来像重点”的块，都会抬高判断成本。
- 好界面不是信息最少，而是让用户少走冤枉眼神。

### 3. 拥挤会降低辨识

- 密集、相似、重复的小元素容易在外围视觉里糊成一团。
- 当页面出现大量徽标、状态点、细粒度按钮、密集图标时，要优先拉开间距、做分组、增强对比。
- 如果只能靠鼠标悬停才看明白，通常已经说明默认视觉设计失败。

### 4. 图像和形状通常比文字更快建立记忆

- 趋势、分布、比例、异常点，通常更适合图表、图形标记或布局对比。
- 文字适合承载精确定义、规则、例外说明，不适合承担全部认知负担。
- 图形化不是装饰化；无意义插画和业务理解无关，不能算“信息图形化”。

### 5. 细微变化不可靠

- 颜色轻微变浅、数字悄悄刷新、按钮轻微位移，这类变化很容易被忽略。
- 重要状态变化必须增加更明确的差异：位置、形状、大小、文案、动效或组合提示。
- 不要把关键反馈藏在用户视线之外，更不要要求用户自己发现。

### 6. 动效应服务空间记忆

- 好动效帮助用户理解“这个东西从哪来、变成了什么、现在在哪”。
- 坏动效只是抢视线，打断扫读节奏，让页面显得轻浮。
- 列表刷新、抽屉展开、页面切换都应优先保证连续性和定向感。

## 面向 UI 评审的翻译

- “把重要内容放中间” 不等于机械居中，而是建立稳定主焦点。
- “减少文字” 不等于删信息，而是压缩冗余句子，把信息转成层级、图表、分组和符号。
- “增强对比” 不等于所有元素都上高饱和，而是让主次差异足够明显。
- “提高密度” 不等于缩字号，而是用更短路径完成更高价值的阅读。

## 联网优先级

- 学术/权威视觉认知资料：PubMed、NCBI、大学或研究机构公开资料。
- 设计系统规范：Apple Human Interface Guidelines、Material 3、IBM Carbon、Ant Design、GOV.UK Design System。
- 竞品页面：优先真实产品官网、公开截图、官方演示，而不是转述文章。
